# 跨境电商 AI Agent

> 面向"AI Agent 开发工程师"岗位的求职项目。基于 LangChain + RAG + ReAct + Function Call，构建一个跨境电商运营智能体，覆盖知识检索、工具调用、多任务编排、幻觉治理、Listing 生成等核心能力。

## 一、项目简介

跨境电商卖家日常面临平台规则查询、关税/汇率计算、产品 Listing 撰写等多类任务，传统做法需在多个系统间来回切换。本项目用 AI Agent 统一编排：用户用一句自然语言，Agent 自主决定调用哪些工具与知识，端到端完成任务，并对回答做幻觉校验。

**核心能力**
- RAG 知识库：平台政策 / 选品指南 / 物流关税规范，BGE 向量化 + Chroma 持久化
- 工具调用：关税查询、汇率换算、Listing 生成、知识检索（Function Call）
- 多任务编排：单次对话串联多工具（查知识→算关税→换算汇率）
- 幻觉治理：溯源校验 + 置信度评分 + 低置信度风险标注
- 可观测性：工具链、召回数、耗时、grounded 标志全链路日志

## 二、技术栈

| 层 | 技术 |
|----|------|
| 编排框架 | LangChain (Agent / Tool / TextSplitter) |
| 向量库 | Chroma |
| Embedding | BGE-small-zh-v1.5 (HuggingFace) / OpenAI |
| LLM | OpenAI 兼容接口 (DeepSeek / 通义千问 / OpenAI) |
| Agent 模式 | ReAct + Function Call (create_tool_calling_agent) |
| 数据库 | MySQL（日志/Listing存档/汇率关税快照，可降级） |
| Web 服务 | FastAPI + Uvicorn |
| 交互 | 命令行 Demo（无复杂前端） |

## 四、快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env   # 填入 LLM_API_KEY 等

# 3. （可选）初始化 MySQL
mysql -u root -p < 数据/数据库初始化.sql

# 4. 首次构建向量知识库
python -c "from 模块.切片向量化 import build_vectorstore; build_vectorstore(force_rebuild=True)"

# 5. 启动命令行演示
python 演示/命令行演示.py

# 6. 启动 API + Web 前端（推荐面试演示）
python 接口/FastAPI服务.py
#   浏览器打开 http://localhost:8000 即可使用 Web 界面

# 7. 运行测试
python 测试/测试日志.py
```

> 详细步骤见 [部署步骤.md](部署步骤.md)

## 五、演示示例

**自然语言多任务**：
```
🧑 你> 蓝牙音箱出口美国电子产品，货值500美元，查关税并换算成人民币
🤖 Agent 思考中...
  -> 调用 检索跨境电商知识(美国电子产品关税政策)
  -> 调用 查询关税(美国, 电子产品, 500)
  -> 调用 汇率换算(125, USD, CNY)   # 500*25%关税=125
🤖 回答: 美国电子产品关税25%，应缴关税125美元，约合899.38元人民币...
```

**快捷指令**：
```
/listing 蓝牙音箱 amazon en      # 生成亚马逊英文 Listing
/tariff 美国 电子产品 500         # 查关税
/currency 500 USD CNY            # 换算汇率
/stats                           # 查看运行统计
```
