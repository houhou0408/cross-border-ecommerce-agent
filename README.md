# 跨境电商 AI Agent

> 面向「AI Agent 开发工程师」岗位的求职项目。基于 LangChain + RAG + ReAct + Function Call，构建一个跨境电商运营智能体，覆盖知识检索、工具调用、多任务编排、幻觉治理、多模态内容生成（视频/图片）、用户认证等核心能力，配备完整 React 前端与效果评估体系。

---

## 一、项目简介

跨境电商卖家日常面临平台规则查询、关税/汇率计算、产品 Listing 撰写、选品分析、物流时效查询、营销素材生成等多类任务，传统做法需在多个系统间来回切换。本项目用 AI Agent 统一编排：用户用一句自然语言，Agent 自主决定调用哪些工具与知识，端到端完成任务，并对回答做幻觉校验。

### 核心能力

| 能力域 | 说明 |
|--------|------|
| **RAG 知识库** | 平台政策 / 选品指南 / 物流关税规范，BGE 向量化 + Chroma 持久化，混合检索（向量 + 关键词重排） |
| **10 大工具调用** | 知识检索、关税查询、汇率换算、Listing 生成、选品分析、利润计算、物流时效、图生视频、文生视频、卖点图生成 |
| **多任务编排** | 单次对话串联多工具（查知识 → 算关税 → 换算汇率 → 算利润） |
| **幻觉治理** | 六步校验：未命中检测 → 关键词覆盖 → 绝对化词惩罚 → 长度检查 → 数字核查 → 归一化评分 |
| **多轮对话记忆** | 会话隔离 + 上下文注入 + 双层持久化（MySQL + JSON 降级） + 自动截断 |
| **多模态生成** | 图生视频（HappyHorse R2V）、文生视频（Wan2.1 T2V）、卖点图生成（Wan2.1 T2I，4 种营销图） |
| **实时数据采集** | 在线汇率 API + 选品热度采集，三级降级（API → DB → 内置数据），1 小时缓存 |
| **用户认证** | 注册 / 登录 / token 校验，pbkdf2 密码哈希，JSON 文件存储零依赖 |
| **效果评估** | 16 条三档判分测试集（易/中/难），幻觉治理与命中统计 |
| **可观测性** | 工具链、召回数、耗时、grounded 标志全链路日志（文件 + MySQL + 内存统计） |

## 二、技术栈

| 层 | 技术 |
|----|------|
| 编排框架 | LangChain 1.x (create_agent / Tool / TextSplitter，基于 langgraph) |
| 向量库 | Chroma 1.5（持久化存储） |
| Embedding | BGE-small-zh-v1.5 (HuggingFace 本地) / OpenAI Embedding |
| LLM | OpenAI 兼容接口（DeepSeek / 通义千问 / OpenAI 可切换） |
| Agent 模式 | ReAct + Function Call 双引擎 |
| 多模态 | 阿里云百炼 DashScope（HappyHorse R2V + Wan2.1 T2V/T2I） |
| 数据库 | MySQL 8.0（日志/会话/Listing存档/汇率关税快照，可降级） |
| Web 服务 | FastAPI + Uvicorn |
| 前端 | React 18 + Vite 5（纯净手写，无 UI 库依赖） |
| 认证 | pbkdf2_hmac 密码哈希 + token 机制（零外部依赖） |
| 中文 NLP | jieba 分词（关键词重排 + 幻觉校验） |

### 核心设计模式

| 模式 | 说明 |
|------|------|
| **双层存储降级** | MySQL 优先 → JSON 文件/内置数据降级，保证无库环境可演示 |
| **三级数据缓存** | 内存缓存(TTL 1h) → MySQL 快照 → 在线 API → 内置降级数据 |
| **RAG-guided 生成** | Listing 生成前先检索平台合规要求，约束 LLM 输出降低违规 |
| **混合检索** | 向量召回(0.7 权重) + jieba 关键词重排(0.3 权重) + 阈值过滤 |
| **双上下文幻觉校验** | kb_context(溯源) + tool_context(事实支撑) 双重校验，避免工具结果被误判 |
| **零外部依赖认证** | pbkdf2_hmac 标准库哈希 + JSON 文件存储，无需 bcrypt/jwt 库 |

## 五、快速开始

### 环境要求

- Python 3.10+
- Node.js 18+（前端构建）
- MySQL 8.0（可选，无库自动降级）

### 安装与启动

```bash
# 1. 安装 Python 依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 LLM_API_KEY、DASHSCOPE_API_KEY 等

# 3.（可选）初始化 MySQL
mysql -u root -p < 数据/数据库初始化.sql

# 4. 首次构建向量知识库
python -c "from 模块.切片向量化 import build_vectorstore; build_vectorstore(force_rebuild=True)"

# 5. 构建前端
cd 前端/react-app
npm install
npm run build
cd ../..

# 6. 启动服务
python 接口/FastAPI服务.py
# 浏览器打开 http://localhost:8000

# 7.（可选）运行效果评估
python -c "from 模块.效果评估 import get_evaluator; print(get_evaluator().run_all())"
```

## 九、核心设计亮点

### 1. 幻觉治理六步校验

```python
# 模块/幻觉治理.py
def verify(self, answer, context, tool_context=""):
    # 1. 知识库未命中检测（区分 kb_miss + tool_context 支撑）
    # 2. jieba 关键词覆盖率（0.5 权重）
    # 3. 绝对化词惩罚（-0.15：100%/绝对/永远/保证）
    # 4. 长度检查（>1200字 -0.1）
    # 5. 数字核查（答案数字是否在工具返回中）
    # 6. 归一化（基础分 0.3 + 覆盖加权）
```

### 2. 双上下文校验（避免误判）

```python
# kb_context: 仅 search_kb 返回 → 溯源 + 未命中检测
# tool_context: 所有工具返回 → 事实支撑校验（关税/汇率数字）
# 综合支撑上下文 = kb_context + tool_context
```

### 3. 混合检索

```python
# 向量召回（0.7 权重）+ jieba 关键词重排（0.3 权重）
fusion = 0.7 * vec_score + 0.3 * kw_score
# 阈值过滤：score < 0.35 视为未命中
```

### 4. 三级数据降级

```
汇率采集：内存缓存(1h) → MySQL 快照 → 在线 API → 内置 12 币种
选品热度：内存缓存(1h) → MySQL 快照 → 在线采集 → 内置 5 品类基线
```

### 5. 多模态生成

| 能力 | 模型 | 用途 |
|------|------|------|
| 图生视频 | HappyHorse 1.1 R2V | 商品图 → 宣传视频 |
| 文生视频 | Wan2.1 T2V Turbo | 文字描述 → 创意短片 |
| 卖点图 | Wan2.1 T2I Turbo | 商品图 → 4 种电商营销图 |
