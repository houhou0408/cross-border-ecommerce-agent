# 跨境电商选品指南知识库

## 1. 选品核心原则
- 轻小件优先：重量低于 2kg、体积小，可显著降低国际物流成本。
- 季节性提前布局：北半球万圣节/圣诞节备货需提前 2-3 个月。
- 避开红海类目：手机壳、数据线等标品竞争激烈，新卖家难突围。

## 2. 热门品类分析

### 2.1 家居收纳
- 客单价 15-40 美元，复购率中等，适合亚马逊与 Temu。
- 趋势：环保材质（竹纤维、再生塑料）受欧美消费者青睐。

### 2.2 宠物用品
- 欧美宠物市场规模超 1300 亿美元，年增速约 5%。
- 推荐子类目：智能喂食器、宠物定位项圈、可降解拾便袋。

### 2.3 户外运动
- 露营装备、骑行配件需求稳定，客单价 20-80 美元。
- 注意：部分登山装备需提供承重检测报告。

## 3. 定价策略
- 成本 = 采购成本 + 头程物流 + 平台佣金 + 尾程 + 退货损耗（按 5% 估）。
- 目标毛利率建议不低于 30%，否则难以覆盖广告与库存成本。
- 使用"渗透定价"切入新市场，待评分积累后逐步提价。

## 4. 竞品分析方法
- 抓取竞品 Review 中的差评关键词，找出痛点改进产品（差异化选品）。
- 关注 BSR（Best Seller Rank）波动，判断类目真实销量。
- 工具推荐：Jungle Scout、Helium 10、卖家精灵。
